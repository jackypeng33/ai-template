## Overview

Sistine Starter uses [Better Auth](https://better-auth.com/) for authentication, supporting email/password login and optional Google and GitHub OAuth.

### Supported Auth Methods

- **Email + Password** — Traditional registration with email verification
- **Google OAuth** — Optional social login via Google accounts

### Registration Flow

1. User submits name, email, and password
2. Account is created with email verification pending
3. System grants **300 bonus credits** (`registration_bonus`)
4. Verification email is sent via Resend
5. User verifies email to unlock full access

### Configuration

The auth configuration lives in `lib/auth.ts`:

```typescript
const google = getGoogleAuthProvider();
const github = getGitHubAuthProvider();

export const auth = betterAuth({
  database: drizzleAdapter(db, { provider: "pg" }),
  emailAndPassword: { enabled: true },
  socialProviders: {
    ...(google ? { google } : {}),
    ...(github ? { github } : {}),
  },
  // lib/auth.ts also defines the user-create registration bonus hook.
});
```

Each OAuth provider requires its own complete credentials; disabled buttons are hidden on login, signup, and `/rap`. See [Auth Providers](./providers) for setup. The user-create hook grants the registration bonus for email and OAuth signups, without granting again on login or account linking.

### Session Management

- Sessions are stored in the `session` table
- Session validation checks ban status (`isBanActive()`)
- Protected routes use `getActiveSessionUser()` from `lib/auth/session.ts`

### Route Protection

| Route Group | Protection |
|-------------|-----------|
| `(protected)` | Requires login — `SessionGuard` component |
| `(admin)` | Requires `role='admin'` — `AdminGuard` component |
| `(auth)` | Public — accessible without login |
| `(marketing)` | Public |
